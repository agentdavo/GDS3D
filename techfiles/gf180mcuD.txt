# GDS3D process definition for GlobalFoundries gf180mcuD (5LM_1TM_11K).
#
# HEIGHTS ARE NOT INVENTED. Every Height/Thickness below is taken from the
# PDK's own KLayout 2.5D view definition:
#
#   libs.tech/klayout/tech/d25/gf180mcu.lyd25
#
# which gives, in nm:
#
#   Poly2      0    +200
#   Contact    0    +860     (not over poly; over poly it is 200 +660)
#   Metal1     860  +550
#   Via1      1410  +600
#   Metal2    2010  +550
#   Via2      2560  +600
#   Metal3    3160  +550
#   Via3      3710  +600
#   Metal4    4310  +550
#   Via4      4860  +900     (not under FuseTop; under it, 4902 +563)
#   FuseTop   4902  +295     (MIM-B top plate, between M4 and M5)
#   Metal5    5760  +1192.5
#
# Metal5's 1192.5 nm agrees with the 1.19 um quoted for the D variant's
# 11 kA top metal, so this is the real stack and not a generic guess.
#
# Layer/datatype numbers are from DRM section 4.1. Watch the two easy
# mis-reads: Via3 is 40/0 and Via4 is 41/0 -- they are NOT in numeric order
# with the metals -- and MetalTop 53/0 / Via5 82/0 belong to the 6LM option
# and are absent on D, so they are listed with Show: 0.
#
# Usage:
#   linux/GDS3D -p techfiles/gf180mcuD.txt -i <file.gds> [-t <topcell>]
