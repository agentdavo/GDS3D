703 cells across 11 libraries; 703 rendered so far. Videos appear as the background render completes — reload to pick up new ones.

3D views are exploded by layer and spun 360°, rendered headless via an EGL backend for GDS3D. Explode distance is scaled per library: the offset is absolute in microns, so the value that suits a 350 µm I/O pad would throw a 3 µm standard cell off screen.
